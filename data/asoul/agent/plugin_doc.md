# 小然 Bot 功能速览

群 @小然 / 私聊直接说话即可聊天，也可用指令：

- `/今日运势`（`/抽签`）每日一签
- `/发病小作文`（`/发病`）
- `/抽老婆`
- `/今天吃什么` / `/今天喝什么`
- `/本周日程`（`/日程`）
- 然然养成（虚拟宠物）：`/签到`、`/然然状态`、`/投喂 <食物>`、`/玩耍 <项目>`、`/打工 <工作>`、`/互动 <动作>`、`/日常 <活动>`、`/换装 <名称>`、`/解锁 <名称>`、`/然然衣柜`、`/然然帮助`
- 开播订阅（群聊）：`/订阅开播 [UP主]`、`/取消订阅 [UP主]`、`/订阅列表`（需群主开启主动推送）
- `/关于小然`（`/小然` `/菜单` `/帮助`）、`/我的id`

# 表情包库（agent 聊天情绪用）

表情包 = 聊天中表达情绪的小图。agent 在情绪到位时通过 `send_sticker` 工具随机挑一张发送，
作为独立图片消息跟在文字回复后面。

## 用法

- 直接把图片丢进本目录即可，**无需重启**（每次发送时重新扫描目录）。
- 支持 png / jpg / jpeg / gif / webp / bmp。

## 标签（agent 怎么找到你的图）

- **默认**：文件名即标签。`然然_开心_笑.jpg` 会生成标签 `然然`、`开心`、`笑`、`然然_开心_笑`，
  分隔符支持 `_`、`-`、空格、`·`。
- **精确控制**（可选）：在上级目录的 `stickers_index.json` 里登记：

```json
{
  "然然_开心_笑.jpg": {"tags": ["开心", "大笑", "嘿嘿"], "desc": "然然笑到眯眼"}
}
```

未登记的文件继续用文件名兜底。图片首次发送时自动上传 COS
（前缀 `static/agent/sticker`），之后走 manifest 缓存，重复发送零上传。

## 相关

- 图片库（主题图）在 `../images/`，两者相互独立。
- SUPERUSER 可用 `/图床同步 static/agent/sticker` 批量预上传。
